# 📖 Overview

**Fatora** is a modern Flutter application designed with a clean architecture, responsive UI, and high performance.

The project follows Flutter best practices and focuses on providing a smooth user experience across Android, iOS, Web, Windows, Linux, and macOS.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/MadY119/fatora.git
```

## Go to project

```bash
cd fatora
```

## Install Packages

```bash
flutter pub get
```

## Run

```bash
flutter run
```

---

# 📦 Build APK

```bash
flutter build apk --release
```
